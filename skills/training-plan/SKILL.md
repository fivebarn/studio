# Training Plan

Build a plan that fits the user's life and adjust it based on how training is actually going.

## Steps
1. **Ask only what's missing:** goal and race date, current weekly activity (or recent workouts), longest recent run or session, days per week available, injuries, and any time limits.
2. **Pull recent data** from a connected fitness app if available (last 4–8 weeks: distance, time, pace, heart rate, frequency). Otherwise use what the user tells you.
3. **Summarize the baseline:** weekly volume, consistency, easy vs. hard effort, and trends.
4. **Build the plan:**
   - phases: base → build → peak → taper
   - each week: easy runs, one quality session (tempo or intervals), one long run, rest days, optional strength or mobility
   - increase weekly volume gradually, with an easier week every 3–4 weeks
   - effort described in plain terms (easy = can hold a conversation)
5. **Show it as a week-by-week table**, and offer to add workouts to the calendar.
6. **Weekly check-in:** compare planned vs. done, look at how the user feels, and adjust. Back off after missed weeks, illness, or soreness.

## Output
A baseline summary, a week-by-week plan table, and adjustment notes after each check-in.
